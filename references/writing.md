# 文风：去 AI 腔、去公文腔、人事分寸

## 一、出稿前逐条过

1. **没有"进行了/开展了/完成了 + 名词"**。写"核对了三份材料"，不写"对材料进行了核对"。
2. **没有"首先/其次/最后""一方面/另一方面"**当骨架。段落靠内容推进，不靠序号词。
3. **没有零主语评论**："值得注意的是""需要指出的是""可以看出"——删掉，直接说事。
4. **句子长短不齐**。连续三句都是 30 字以上，或者每段都是四行，就是在露机器痕迹。
5. **不加没信息量的过渡**："在此基础上""综上所述""总而言之"。会议纪要不需要收束句。
6. **不用形容词代替结论**："效果显著""意义重大""高度重视"——换成具体事实或数字。
7. **比喻只留会上的**。自己造的"打通最后一公里""形成闭环"不要。
8. **加粗不均匀**。全文加粗超过 10 处，说明没做取舍。

## 二、公文腔对照

| 别写 | 写 |
|---|---|
| 对方案进行了深入讨论 | 讨论集中在两点：预算和工期 |
| 系统梳理了现有问题 | 列出七个问题，其中三个影响交付 |
| 与会人员一致认为 | 定下来：先做 A，B 往后放（有分歧就写分歧） |
| 进一步优化完善 | 补一页附件，把验收单和发票放进去 |
| 高度重视、狠抓落实 | 删掉，换成谁在什么时候做什么 |
| 取得了阶段性成果 | 主体部分定稿，附件待补 |

## 三、人事分寸

一条原则：**对事不留情，对人留名分**。

| 情形 | 写法 |
|---|---|
| 材料本身差 | 直接判："这版封面太假""数据对不上台账"。不写"有待提升" |
| 某人做的东西有问题 | 落到物上："封面图是合成图"，不写"某某做得不用心" |
| 对个人的负面评价 | 不引述原话，只留结论与改法 |
| 上级或专家的意见 | 归纳模式不写出处；叙事模式写"X老师提出"，不加工语气 |
| 争论没结论 | 写清分歧点与下次再议，不硬凑一个结论 |

## 四、四个常见塌方

- **流水账**：按时间顺序记"先说了 A，然后说了 B"。改：按主题重组。
- **只有结论**：读者不知道为什么这么定。改：每条补一句依据。
- **均匀加粗**：每段一句加粗，等于没加粗。改：全文 5–10 处，只留会影响决策的。
- **补全**：会上没定的时间、没提的负责人，被写成确定项。改：标"待定/待确认"。
